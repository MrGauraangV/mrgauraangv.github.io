Files:
  index.html          Home page
  about.html          About Me and education
  research.html       Current research and research figure
  publications.html   Publications / preprints landing page
  talks.html          Talks and posters
  more.html           Previous projects, toolkit, outreach and awards
  style.css           Shared design and navigation styling
  cv.pdf              CV linked from the circular CV icon
  research-portfolio.pdf  Research portfolio linked from Research page
  dust-model-results.png  Combined research figure
  profile.jpg         YOUR PORTRAIT (upload this separately if not already present)

The portrait is displayed with max-width/max-height and object-fit: contain so the full image remains visible.
The page background is the ALMA image of HL Tauri, loaded from ESO's CDN. The attribution is in the footer of every page.

HOW TO PUBLISH:
1. Extract the ZIP.
2. In your GitHub repository, upload all these files to the repository ROOT (not inside another folder).
3. Keep your existing profile.jpg in the root, or upload your selected portrait and name it profile.jpg.
4. Commit to main. GitHub Pages should deploy automatically if it is already enabled for main / (root).
5. Visit https://mrgauraangv.github.io/ .

The navigation links now open separate HTML pages. They do not scroll to sections on one long homepage.
